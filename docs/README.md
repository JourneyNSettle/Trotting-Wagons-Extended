# Wagons

The player overview is the [README.md](../README.md) at the repository root. The files in this folder describe the current code.

They describe the `dev` branch, Minecraft 1.21.1, NeoForge. Item, entity, config, and tag names match the sources. Numbers are taken from the code, including places where a config key and the value the constructor actually reads disagree.

Mod: `trotting_wagons`, display name Trotting Wagons Extended, `mod_version` 2.0.0. Config file: `config/trotting_wagons-server.toml`. The side in `neoforge.mods.toml` is `BOTH`: the mod belongs on the server and on every client.
