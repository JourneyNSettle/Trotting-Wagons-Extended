# Конестога

Предмет и сущность `trotting_wagons:conestoga_wagon`. Класс `ConestogaWagon` расширяет `AbstractInventoryWagon`. В `en_us` имя Conestoga Wagon. В `ru_ru` ключа нет, поэтому в русской локали остаётся английское имя.

## Параметры

| Параметр | Значение |
| --- | --- |
| Хитбокс | `sized(3.0, 2.9)` — след 3×3, высота 2.9 |
| Здоровье | `conestoga_wagon_health`, по умолчанию 60 |
| Коэффициент скорости | `conestoga_wagon_speed_coefficient`, по умолчанию 0.8 |
| Поворот | `conestoga_wagon_turn_rate`, по умолчанию 2.0 |
| Ускорение в конфиге | `conestoga_wagon_acceleration`, по умолчанию 2.0, вождение не читает |
| `wheelWidth`, `wheelLength` | 1, 1 |
| Упряжь | 2 слота, `horseX` 0.6, `horseY` 3.6, `shaftAngle` 13 |
| Дышло | длина по умолчанию 57.12/16, высота 7.5/16, запасная цель 0.85 |
| Просадка | оба задних и диагональ −14° |
| Груз | 108 обычных слотов, стак до максимума предмета |
| Цвет | по умолчанию белый, текстура `textures/entity/conestoga_wagon/<цвет>.png` |

Кости колёс, слева направо и спереди назад: `wheelleft`, `wheelright`, `bone`, `bone2`. Одна сетка на все три вида колёс. Зоны клика в пикселях модели, Y вверх, Z вперёд модели (в сущности перед — минус эта Z):

| Угол | X | Y | Z |
| --- | --- | --- | --- |
| 0 | 16 | 7.15385 | −16 |
| 1 | −16 | 7.15385 | −16 |
| 2 | 16 | 8.5 | 17 |
| 3 | −16 | 8.5 | 17 |

## Места

Координаты в блоках от центра сущности, +Z — вперёд повозки. При посадке точка ещё опускается на 0.7 под сидящую позу.

| Индекс | Позиция | Вид |
| --- | --- | --- |
| 0 | (0, 1.25, 2.1) | `DRIVER` |
| 1 | (−0.4375, 1.18, 1.1) | `PLAYER` |
| 2 | (0.4375, 1.18, 1.1) | `PLAYER` |
| 3 | (−0.4375, 1.18, 0.1) | `UNIVERSAL` |
| 4 | (0.4375, 1.18, 0.1) | `ANIMAL` |
| 5 | (0, 1.18, −1.81) | `ANIMALBIG` |

Заднее большое место принимает любого не-игрока, не только крупного пассажира. Крупный пассажир на места 3 и 4 не садится.

## Интерфейс и рецепт

Меню `ConestogaMenu` на общем экране инвентарной повозки: слоты груза, кнопки мест, два слота упряжи, четыре колеса, инвентарь игрока, починка 2×2 на (270, 226). Рамки починки рисуются только пока слот активен. Над ними, по центру, `gui.trotting_wagons.durability` и `conditionName()`. Имя владельца стоит в строке названия, по центру ширины 320, и сдвигается влево только чтобы не наехать на счётчик пути. Счётчик в той же строке справа. Полоска прочности — общая для этого семейства экранов.

Shift-клик материалом починки за один жест заполняет каждый открытый слот, который его принимает. Остаток остаётся у игрока. Следующий Shift-клик, когда починка больше ничего не берёт, кладёт остаток в груз. Колёса идут только в слоты колёс. Из ячеек повозки, включая починку, предмет уходит игроку.

Рецепт `conestoga_wagon`, форма 3×3:

```
SSS
PCP
WWW
```

`S` — `minecraft:white_wool`, `P` — `minecraft:spruce_planks`, `C` — `minecraft:chest`, `W` — `trotting_wagons:wheel`.

Груз при уничтожении выпадает обычным `Containers.dropContents` после колёс: каждый стак — отдельная сущность предмета. Предметы починки не выпадают.
