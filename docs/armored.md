# Броневая повозка

Предмет и сущность `trotting_wagons:armored_wagon`. Класс `ArmoredWagon` расширяет `AbstractWagon` и сам реализует `MenuProvider`. Своего грузового инвентаря нет. В `en_us` имя Armored Wagon. В `ru_ru` ключа нет, поэтому в русской локали остаётся английское имя.

## Параметры

| Параметр | Значение |
| --- | --- |
| Хитбокс | `sized(3.0, 2.9)` |
| Здоровье | `armored_wagon_health`, по умолчанию 120 |
| Коэффициент скорости | `armored_wagon_speed_coefficient`, по умолчанию 0.5 |
| Поворот | `armored_wagon_turn_rate`, по умолчанию 2.0 |
| Ускорение в конфиге | `armored_wagon_acceleration`, по умолчанию 4.0, вождение не читает |
| `wheelWidth`, `wheelLength` | 1, 1 |
| Упряжь | 2 слота, `horseX` 0.6, `horseY` 3.6, `shaftAngle` 13 |
| Дышло | длина 61.12/16, высота по умолчанию 7.5/16 |
| Просадка | оба задних и диагональ −14° |
| Груз | нет |
| Цвет | `getDefaultColor` возвращает `null`, стартовая текстура `none.png`; покраска переключает файл цвета |

Кости колёс: `bone3`, `bone4`, `bone`, `bone2`. Зоны клика:

## Интерфейс и рецепт

`ArmoredMenu` / `ArmoredScreen`: кнопки мест, две кнопки упряжи, колёса, инвентарь игрока, починка 2×2 на (270, 113). Рамки починки рисуются только пока слот активен. Над ними, по центру, `gui.trotting_wagons.durability` и `conditionName()`. Имя владельца стоит в строке названия, по центру ширины 320, и сдвигается влево только чтобы не наехать на счётчик пути. Счётчик в той же строке справа. Полоска прочности рисуется на `topPos + 14`, ширина `imageWidth - 32`.

Грузовых слотов нет. Shift-клик материалом починки за один жест заполняет каждый открытый слот, который его принимает, и оставляет остаток у игрока. Повторный клик ничего не переносит. Колёса идут только в слоты колёс. Из ячеек повозки, включая починку, предмет уходит игроку.

Рецепт `armored_wagon`:

```
PPP
LIL
WWW
```

`P` — `minecraft:spruce_planks`, `L` — `minecraft:stripped_spruce_log`, `I` — `minecraft:iron_block`, `W` — `trotting_wagons:wheel`.
