# Королевская повозка

Предмет и сущность `trotting_wagons:royal_wagon`. Класс `RoyalWagon` расширяет `AbstractInventoryWagon`. В `en_us` имя Royal Wagon. В `ru_ru` ключа нет, поэтому в русской локали остаётся английское имя.

## Параметры

| Параметр | Значение |
| --- | --- |
| Хитбокс | `sized(3.0, 2.9)` |
| Здоровье | `royal_wagon_health`, по умолчанию 80 |
| Коэффициент скорости | `royal_wagon_speed_coefficient`, по умолчанию 1.0 |
| Поворот | конструктор читает `conestoga_wagon_turn_rate`, по умолчанию 2.0 |
| Ускорение в конфиге | `royal_wagon_acceleration`, по умолчанию 3.0, вождение не читает |
| `wheelWidth`, `wheelLength` | 1.1, 1.3 |
| Упряжь | 2 слота, `horseX` 0.6, `horseY` 4.3, `shaftAngle` 7 |
| Дышло | длина 64.12/16, высота 10.5/16 |
| Просадка | оба задних и диагональ −14° |
| Груз | 54 обычных слота |
| Цвет | по умолчанию белый, текстура `textures/entity/royal_wagon/<цвет>.png` |

Ключ `royal_wagon_turn_rate` в том же конфиге объявлен и по умолчанию тоже 2.0, но `RoyalWagon` передаёт в `super` поле `conestogaTurnRate`. Пока оба значения совпадают, поворот тот же. Если изменить только королевский ключ, эта повозка останется на повороте Конестоги.

Кости колёс: `octagon2`, `octagon`, `octagon4`, `octagon3`. Сторона берётся по положению куба, не по имени кости. Зоны клика:

| Угол | X | Y | Z |
| --- | --- | --- | --- |
| 0 | 17.75 | 10.5 | −21 |
| 1 | −17.75 | 10.5 | −21 |
| 2 | 17.75 | 10.5 | 21 |
| 3 | −17.75 | 10.5 | 21 |

## Места

Только игроки. Координаты в блоках, +Z вперёд.

| Индекс | Позиция | Вид |
| --- | --- | --- |
| 0 | (0, 1.3, 1.8) | `DRIVER` |
| 1 | (0, 1.45, −0.7) | `PLAYER` |
| 2 | (0.4375, 1.45, 0.7) | `PLAYER` |
| 3 | (−0.4375, 1.45, 0.7) | `PLAYER` |

Животные пассажирами не садятся. Крупному пассажиру места нет.

## Интерфейс и рецепт

Меню `RoyalMenu`: 54 слота груза, четыре места, две кнопки упряжи, колёса, инвентарь игрока, починка 2×2 на (270, 40). Рамки починки рисуются только пока слот активен. Над ними, по центру, `gui.trotting_wagons.durability` и `conditionName()`. Имя владельца стоит в строке названия, по центру ширины 320, и сдвигается влево только чтобы не наехать на счётчик пути. Счётчик в той же строке справа.

Shift-клик материалом починки за один жест заполняет каждый открытый слот, который его принимает. Остаток остаётся у игрока. Следующий Shift-клик, когда починка больше ничего не берёт, кладёт остаток в груз. Колёса идут только в слоты колёс. Из ячеек повозки, включая починку, предмет уходит игроку.

Рецепт `royal_wagon`:

```
LLL
SCS
WWW
```

`L` — `minecraft:stripped_spruce_log`, `S` — `minecraft:white_wool`, `C` — `minecraft:chest`, `W` — `trotting_wagons:wheel`.
